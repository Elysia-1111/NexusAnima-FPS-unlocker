# v1.1 · Automatic minimization to tray and improved context menu

**Honkai: Nexus Anima FPS Unlocker** · Developer: **MissPinkElf**

## What's changed

- **Automatically hide in the system tray:** After a successful game launch or when you click Minimize, the main window hides in the system tray and continues maintaining the frame-rate setting in the background. It no longer occupies a regular taskbar button.
- **Tray shortcuts:** Left-click the tray icon to reopen the main window. The right-click menu offers **打开工具 (Open tool)** and **退出 (Exit)**. Exiting automatically restores the game's original frame-rate limit.
- **Consistent appearance:** The tray context menu now matches the main window, with a rounded dark indigo background and mint highlights, plus refined icons and spacing.

## Download and use

1. Download **`NexusAnimaFPS-MissPinkElf-v1.1.zip`** from **Assets** below and extract the entire archive.
2. Make sure the game is not running, then open **`NexusAnimaFPS.exe`**.
3. Enter a whole-number frame rate from `1–240` (default: `240`), click **启动游戏 (Launch game)**, and allow administrator permission when prompted.

> For detailed game path setup and frequently asked questions, see the [README](https://github.com/Elysia-1111/NexusAnima-FPS-unlocker/blob/main/README.en.md) on the repository's home page.

## Compatibility notes

- **Supported version:** Only the Windows version of Honkai: Nexus Anima **0.75.0 (the installation package supported by this release)**. Updating the game or using another installation package may cause a “Version mismatch” message.
- **Runtime requirement:** Verified on **64-bit Windows 11**. Requires **.NET Framework 4.8.1**. If it is missing, [download the Runtime from Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net481).
