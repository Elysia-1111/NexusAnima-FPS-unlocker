# 崩坏：因缘精灵 FPS 解锁工具

[English](README.en.md)

2026年不会还有PC游戏锁60帧吧？用于突破《崩坏：因缘精灵》Windows 版帧率上限的小工具，由 **MissPinkElf** 开发。

支持自定义 **1–240 FPS**（默认 **240**），工具会自动记住上次的帧率与游戏路径。游戏启动后自动收起至系统托盘并在后台维持帧率，正常退出时自动恢复游戏原本的帧率上限（通常为 60 FPS）。

> **使用前提（必读）：**
> - **仅限游戏未运行时使用**：请先彻底退出游戏，再通过本工具启动；工具不会接管已在运行的游戏。
> - **版本限制**：目前仅适配《崩坏：因缘精灵》Windows 版 **0.75.0（三测对应的安装包）**。游戏更新或使用不同安装包可能导致“版本不匹配”，需等待工具适配。
> - **运行环境**：已验证 **Windows 11（64 位）**，依赖 **.NET Framework 4.8.1**。如果打开工具报错或无反应，请先前往 [微软官网下载 .NET Framework 4.8.1 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net481) 并安装（无需下载 Developer Pack）。

## 快速上手

1. **下载与解压**
   前往本仓库的 **[Releases](https://github.com/Elysia-1111/NexusAnima-FPS-unlocker/releases/latest)** 页面，下载最新附件 **`NexusAnimaFPS-MissPinkElf-v1.2.zip`**。将其完整解压到任意独立文件夹，无需放入游戏目录。
2. **启动游戏**
   运行解压后的 **`NexusAnimaFPS.exe`**，输入目标帧率（1–240 的整数，如 `120`、`144`、`240`），点击 **启动游戏**。
   *若弹出 Windows 管理员权限确认框，点击“是”即可（工具需要权限以写入帧率设置）。*
3. **后台运行**
   工具检测到游戏启动并应用帧率后，会自动缩小到系统托盘（任务栏右下角，可能在 `^` 折叠菜单里）。窗口消失属于正常现象，请保持工具在后台运行。

## 手动指定游戏路径

如果工具未能自动识别游戏位置：

1. 点击主界面右上角的 **齿轮图标**。
2. 先尝试点击 **自动识别**；如果仍找不到，点击 **选择游戏文件**。
3. 找到游戏安装目录，选中游戏本体 **`NexusAnima.exe`**（通常位于 `games` 或 `NexusAnima Game` 文件夹内，**不要**选桌面快捷方式、启动器或本工具自身）。
4. 确认底部显示路径已就绪后，关闭设置页即可，路径会自动保存。

## 常见问题

**Q：设了 240 FPS，为什么游戏里没跑满？**
工具修改的是帧率上限，实际帧数受显卡性能、画面设置、垂直同步（V-Sync）及显卡驱动限帧影响。另外，工具界面显示的是你设定的目标值，不是实时帧率监控。

**Q：游戏运行中能直接改帧率吗？**
暂不支持。运行期间帧率输入框会锁定，如需调整，请先退出游戏，再修改数值并重新启动。

**Q：提示“游戏访问被拒绝”怎么办？**
请确认已彻底关闭游戏，重新打开工具并在弹出 Windows 权限提示时允许管理员运行。如果依然报错，将鼠标悬停在主界面底部的状态提示上查看具体原因。

**Q：退出工具后帧率没恢复怎么办？**
正常退出工具会自动恢复原帧率。工具异常退出时也会尝试自动恢复；如果仍未恢复，只需正常退出游戏再重新打开一次即可重置。

## 更新与卸载

- **更新**：先退出游戏，再右键托盘图标退出旧版工具，将新版压缩包解压覆盖到原文件夹即可（放在新文件夹需重新设置路径）。工具无自动更新功能。
- **卸载**：绿色软件无需卸载，先正常退出游戏和工具，再删除整个文件夹即可。
